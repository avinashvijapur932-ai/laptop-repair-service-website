Laptop Repair Service Website

A responsive laptop repair service website built with HTML, CSS, and JavaScript.

📌 Project Overview

This project is a modern website concept for a laptop repair business. It provides customers with information about repair services and allows them to submit a repair request.

✨ Features

- Responsive design for mobile and desktop
- Laptop repair service sections
- Screen replacement service
- Battery replacement service
- Motherboard repair service
- Software troubleshooting
- Keyboard and hinge repair
- No Fix, No Fee guarantee
- Repair booking form
- Interactive JavaScript form handling

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📂 Project Structure

laptop-repair-service-website/
├── index.html
├── style.css
├── script.js
└── README.md

How to Run

1. Download or clone this repository.
2. Open "index.html" in any web browser.
3. Explore the website and test the repair request form.

🎯 Purpose

This project was created as a web development portfolio project to demonstrate frontend development skills using HTML, CSS, and JavaScript.
